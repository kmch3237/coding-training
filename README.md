# coding-training

"안 보고 코드 쓰는 실력"을 위한 매일 손코딩 훈련 기록.

## 방법 (3단계 노출 줄이기)
1. 보고 따라치기
2. 가리고, 설명하면서 치기 (막히면 1줄만 확인)
3. 완전히 안 보고 (막히면 다음날 재도전)

## 루틴 (하루 30~60분)
- 복습 10분 (전날 것 안 보고 재현)
- 새 패턴 1개 15~30분
- 기록 5~10분

## 8주 커리큘럼
| 주차 | 테마 |
|---|---|
| 1주 | Java 기초 손코딩 (for/while, 배열, String, 클래스) |
| 2주 | 컬렉션 + 제어구조 |
| 3주 | Spring Controller→Service→Mapper 패턴 복제 |
| 4주 | @Autowired, @RequestMapping 조합 |
| 5주 | MyBatis/SQL CRUD + 페이징 |
| 6~7주 | 알고리즘 (프로그래머스 Lv0~2) |
| 8주 | noExit 리팩토링 1개 설계부터 재구현 |

3일 이상 공백 생기면 그 주차 1일차로 리셋.
